ModelDock es una plataforma web integral diseñada para ingenieros de IA y equipos de desarrollo, que centraliza la gestión de proyectos y el versionamiento de prompts (instrucciones para modelos de lenguaje). A través de un sistema CRUD completo, permite crear, organizar y editar iniciativas y sus respectivas instrucciones de manera segura, garantizando la validación de datos. Además, la aplicación integra un Playground interactivo para simular la ejecución de estos prompts con diferentes modelos de IA, y un Dashboard de monitoreo que registra en tiempo real métricas clave de rendimiento como la latencia y el consumo de tokens, brindando a los equipos control total sobre la eficiencia y los costos de sus aplicaciones basadas en LLMs.
